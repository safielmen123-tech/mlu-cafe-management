Drop menu photos in this folder.

The filename must match the dish you see in the app.
Example: Espresso → espresso.jpg

Then from backend run:
  npm run seed:menu

That copies the photo into frontend/public/menu-images/
and builds a small preview in frontend/public/menu-images/thumbs/

JPG, PNG, or WEBP. Not HEIC.
